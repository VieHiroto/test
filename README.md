# morning-task-organizer

朝のタスク整理アシスタントのMVPです。Siri/手入力の雑タスクを毎朝整理し、カテゴリ分類とカレンダー登録案（ICS）を作ります。

## MVPの使い方
1. タスクを1行1件で入力
2. 「解析する」で分類結果を表示
3. カレンダー登録案を確認してICSをコピー

## 開発コマンド
- npm install
- npm run dev
- npm run test
- npm run lint
- npm run build
