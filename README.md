## StyleAnalyzer.gs - ヘアスタイル画像分析ツール

Google Apps ScriptとGemini AIを使用して、ヘアスタイル画像を自動分析し、ホットペッパービューティー掲載用のデータを生成するツールです。

### 機能

- Google Driveの画像IDからヘアスタイル画像を取得
- Gemini 2.0 Flash APIを使用した画像分析
- 以下の情報を自動生成：
  - 性別（メンズ/レディース）
  - 髪の長さ（ショート/ボブ/ミディアム/ロング等）
  - SEOに最適化されたタイトル（30文字以内）
  - 魅力的な説明文（50文字程度）

### セットアップ

1. Google スプレッドシートを開く
2. 「拡張機能」→「Apps Script」を選択
3. `StyleAnalyzer.gs` のコードを貼り付け
4. スクリプトプロパティに `GEMINI_API_KEY` を設定：
   - Apps Scriptエディタで「プロジェクトの設定」→「スクリプト プロパティ」
   - プロパティ名: `GEMINI_API_KEY`
   - 値: あなたのGemini API Key

### スプレッドシートのフォーマット

| A列 | B列 | C列 | D列 | E列 | F列 | G列 |
|-----|-----|-----|-----|-----|-----|-----|
| 画像ID | ステータス | 画像リンク | 性別 | 髪の長さ | タイトル | 説明 |
| 1234... | | | | | | |

### 使い方

1. A列に Google Drive の画像IDを入力
2. メニューから「スタイル分析ツール」→「画像IDから分析を実行」を選択
3. 処理が完了すると、D〜G列に分析結果が自動入力されます
4. B列のステータスが「完了」になれば処理成功

### 注意事項

- Gemini API Keyが必要です
- 画像はGoogle Driveに保存されている必要があります
- APIの利用制限に注意してください
- 大量の画像を処理する場合は、実行時間制限（6分）に注意してください
